# 📰 Bangla News 24 - News Platform

## 📌 About The Project

Bangla News 24 is a modern Bangla news web application built with **Next.js, TypeScript, Tailwind CSS, Better Auth, and MongoDB**. The application is designed to present news content through a clean, responsive, and user-friendly interface.

The project focuses on practicing modern Next.js concepts, authentication, dynamic content rendering, responsive UI, and database integration.

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Better Auth
* MongoDB
* REST API

## ✨ Key Features

### 📰 News Content

* Display Bangla news articles.
* Organize news into different categories.
* Display important news information clearly.

### 🔥 Latest News

* Highlight important and recent news.
* Clean and organized news layout.
* Easy navigation between news sections.

### 🔐 Authentication

* User registration and login.
* Authentication using Better Auth.
* Protected user-related functionality.

### 🗄️ Database

* MongoDB integration.
* Store and manage application data.
* Dynamic data handling.

### 📱 Responsive Design

* Responsive layout for different devices.
* Mobile-friendly navigation.
* Modern and clean interface.

## 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd bangla-news-24
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.
